# EXPLORA IA
Abre `index.html` en el navegador (no necesita servidor).
- `css/styles.css` estilos · `js/data.js` clases, recursos y carpetas de Drive (edita aquí)
- `js/fx.js` estrellas, destellos y efectos · `js/entregas.js` registro y entregas (IndexedDB) · `js/app.js` vistas y rutas
- `assets/img/` robot y favicon
Las entregas y el registro se guardan solo en el navegador de quien los crea.
